# jr-motion.com

Portfolio de Juan Luis Remis, Motion Graphics Designer 2D/3D (Bizkaia).

- `index.html`: la web completa. Contenido editable en el bloque `SITE` al principio del `<script>`.
- `assets/`: imágenes (personaje del easter egg).
- `thumbs/`: miniaturas o bucles cortos de las tarjetas de proyecto (< 3 MB cada uno).
- `videos/`: solo vídeos cortos. El reel y los vídeos largos van en YouTube o Vimeo (GitHub no admite archivos de más de 100 MB y conviene no acercarse).

Publicada con GitHub Pages desde la rama `main`.
